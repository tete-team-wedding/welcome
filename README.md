## แก้ข้อความ

ช่องที่รอใส่ข้อมูลหน้าตาแบบนี้ `<span class="todo">วันที่ตอบรับ</span>` ให้ลบทั้งก้อนแล้วพิมพ์ข้อมูลจริงแทน

## ความสำเร็จ

ความสำเร็จ ความคืบหน้า และเวลา (ISO 8601) ที่ปลดล็อกแต่ละรายการจะบันทึกไว้ในเบราว์เซอร์ของผู้เข้าชม โดย `achievements.js`
ดูแลการปลดล็อก First Contact และความสำเร็จปกติ ปุ่มรูปถ้วยรางวัลลอยอยู่บนหน้าเว็บ เมื่อปลดล็อกจะแสดงข้อความฉลอง
ไอคอนของแต่ละความสำเร็จตั้งค่าได้จาก `icon` ในรายการความสำเร็จเดียวกัน

### สถิติความสำเร็จ (ไม่เก็บชื่อ)

`achievements.js` จะส่งรหัสผู้เล่นแบบสุ่มที่บันทึกไว้ในเบราว์เซอร์ รหัสความสำเร็จ และเวลาที่ปลดล็อกแต่ละรายการ
ไม่มีชื่อหรือข้อมูล RSVP โดยความสำเร็จ `completionist` และ `the-whole-story` ใช้ระบุผู้เล่นที่เก็บครบทั้งความสำเร็จปกติและความลับ

1. สร้าง Apps Script ที่ผูกกับ Google Sheet ที่ต้องการ แล้ววางโค้ดจาก `achievement-statistics.gs` (หรือกำหนด `SPREADSHEET_ID` ในโค้ด หากเป็น Apps Script แบบ standalone)
2. ปล่อย `SHEET_NAME` ว่างไว้เพื่อให้สคริปต์สร้างแท็บ `Achievement statistics` หรือใส่ชื่อแท็บที่ต้องการภายหลัง
3. Deploy เป็น **เว็บแอป** โดยเลือกให้ทำงานในนามเจ้าของสคริปต์ และอนุญาต **ทุกคน** แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
4. นำ URL ไปใส่ใน `ACHIEVEMENT_STATS_URL` ด้านบนของ `achievements.js`

สคริปต์จะสร้างหัวคอลัมน์บนแท็บที่เลือกเมื่อได้รับข้อมูลครั้งแรก (`Player ID`, `Achievement ID`, `Completed at`, `Received at`) แต่ละแถวเป็นเวลาปลดล็อกหนึ่งรายการของผู้เล่น และไม่บันทึกแถวซ้ำเมื่อผู้เล่นเดิมส่งความสำเร็จเดิมอีกครั้ง ให้นับผู้เล่นที่ทำครบโดยนับรหัส Player ID ที่มีทั้ง `completionist` และ `the-whole-story` หากแก้ Apps Script หลัง deploy ให้เผยแพร่เวอร์ชันใหม่

เวลาของความสำเร็จที่ปลดล็อกก่อนติดตั้งระบบนี้ไม่สามารถกู้คืนจากข้อมูลเดิมได้ ผู้ที่มีครบอยู่แล้วจะถูกนับเมื่อเปิดเว็บหลังติดตั้ง โดยใช้เวลาตรวจพบเป็นเวลาเสร็จสิ้น
Player ID เป็นตัวระบุแบบนามแฝงที่เก็บใน localStorage จึงนับได้ตามโปรไฟล์เบราว์เซอร์เท่านั้น การล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนอุปกรณ์จะสร้าง Player ID ใหม่

## ภาพตัวอย่างเวลาแชร์ลิงก์

เว็บใช้ `images/social-preview-v2.jpg` เป็นภาพตัวอย่างเมื่อแชร์ลิงก์บน LINE, Facebook
และแพลตฟอร์มอื่น ๆ ถ้าเปลี่ยนภาพ ให้อัปเดตไฟล์นี้พร้อมข้อมูล `og:image` ใน `index.html`
และใช้ชื่อไฟล์ใหม่เพื่อให้ LINE ดึงภาพใหม่แทนภาพเดิมที่แคชไว้
หลังเผยแพร่แล้ว แพลตฟอร์มอาจยังแสดงภาพเดิมชั่วคราวเพราะเก็บข้อมูลตัวอย่างไว้ในแคช

## แกลเลอรี (ปัดข้าง วนได้ ดูภาพใหญ่และซูมได้)

ไฟล์อยู่ใน `images/gallery/`
- รูปแต่ละรูปมี 2 ไฟล์: `01.jpg` (ภาพใหญ่ กว้างหรือสูง 2,000 px) และ `01-sm.jpg` (ภาพเล็ก 1,000 px)
- วิดีโอ: `00.mp4`, `00.webm` และ `00-poster.jpg`
- แตะภาพกลางเพื่อดูภาพใหญ่ แล้วกดปุ่มซูมหรือดับเบิลคลิกเพื่อขยาย ลากภาพเพื่อเลื่อนดูส่วนต่าง ๆ

ลำดับและรายการอยู่ใน `script.js` ตรง `var GALLERY = [`
- สลับลำดับ: ย้ายบรรทัดขึ้นลง
- เพิ่มรูป: อัปโหลด 2 ไฟล์ (ภาพใหญ่ + `-sm`) แล้วเพิ่มบรรทัด `{src:'27', w:2, h:3},` (w/h คือสัดส่วน แนวตั้ง 2,3 แนวนอน 3,2)
- ถ้าอยากให้ช่วยย่อรูปให้ ส่งรูปมาในแชตได้

## เชื่อมฟอร์มตอบรับกับ Google Sheet

ตอนนี้เชื่อมกับไฟล์ **T&T_Wedding Planner** (Google Sheet) เรียบร้อยแล้ว ขั้นตอนด้านล่างใช้เมื่อต้องตั้งค่าใหม่เท่านั้น

1. ในไฟล์ Google Sheet ไปที่เมนู **ส่วนขยาย → Apps Script** แล้วลบโค้ดเดิมทิ้ง วางโค้ด Apps Script ของฟอร์มตอบรับ (ไฟล์ `google-apps-script.gs` ไม่ได้อยู่ในโฟลเดอร์นี้ ต้องใช้สำเนาที่เก็บไว้ หรือเปิดโค้ดเดิมจากโปรเจกต์ Apps Script ของ T&T_Wedding Planner) แล้วกดบันทึก
2. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่** แล้วตั้งค่าดังนี้
   - ประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. กดอนุญาตสิทธิ์ แล้ว copy **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
4. ใน `script.js` วางลิงก์ที่ได้ในบรรทัด `var RSVP_URL = '...';`

เมื่อแขกกดส่ง ข้อมูลจะเข้าแท็บ `[Respond]Guest list` ทันที โดยหัวคอลัมน์มีดังนี้
วันเวลาที่ตอบ · ชื่อ-นามสกุล · แก้งค์ · สถานะ · จำนวนคน · ช่วงที่ร่วม · ข้อความถึงบ่าวสาว

- ถ้าแท็บยังว่าง สคริปต์จะสร้างหัวคอลัมน์ให้เองตอนมีคนตอบครั้งแรก
- ถ้าเพิ่มคอลัมน์ของตัวเองภายหลัง สคริปต์จะเขียนเฉพาะคอลัมน์ที่ชื่อตรงกันเท่านั้น
- ถ้าเลือก “อื่นๆ” ในช่องแก้งค์ แขกต้องระบุรายละเอียด และข้อมูลจะส่งเป็น `อื่นๆ: <รายละเอียด>` ในช่อง `gang`; ตรวจสอบว่า Apps Script รองรับคีย์นี้และมีคอลัมน์แก้งค์ก่อนใช้งาน
- ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้องกด Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่ ทุกครั้ง

ถ้า `RSVP_URL` ยังว่าง หรือส่งไม่สำเร็จ ฟอร์มจะให้แขกส่งข้อความทาง LINE แทน
ฟอร์มจะแสดงว่าส่งสำเร็จเมื่ออ่าน JSON ตอบกลับได้และได้รับ `{ "ok": true }` เท่านั้น
ถ้าเบราว์เซอร์แจ้ง CORS เมื่อเรียก Apps Script โดยตรง ให้ใช้ proxy ที่อนุญาต origin ของเว็บไซต์และส่งต่อคำขอไป Apps Script แล้วใส่ URL ของ proxy ใน `RSVP_URL`

## ร้านและที่เที่ยวสุรินทร์

แก้รายการใน `script.js` ตรง `var G = {` โดยเพิ่มหรือแก้ object ใน array ของหมวดที่เกี่ยวข้อง แต่ละ object ใช้ข้อมูลดังนี้:

- `n`: ชื่อสถานที่
- `lat` / `lng`: พิกัดหมุดบนแผนที่
- `id`: Google Place ID (เว้นว่างได้)
- `m`: ที่ตั้งและเวลาเปิด
- `d`: คำอธิบาย

หมวดที่ใช้เป็น key ของ `G` คือ `ร้านกาแฟ`, `ร้านมัจฉะ`, `ร้านอาหาร` และ `ที่เที่ยว` เว็บไซต์ใช้ข้อมูลใน `script.js` โดยตรง

วิธีหาพิกัด: เปิด Google Maps แล้วคลิกขวาที่ตำแหน่งร้าน จะเห็นตัวเลข เช่น `14.8786, 103.5052` กดตัวเลขนั้นเพื่อ copy
